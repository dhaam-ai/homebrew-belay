# homebrew-belay

Homebrew tap for [belay](https://github.com/dhaam-ai/belay) — a durable,
resumable orchestrator for autonomous coding agents.

```bash
brew tap dhaam-ai/belay
brew install belay
```

`Formula/belay.rb` is generated by goreleaser on each belay release. Do not
edit it by hand: the next release overwrites it, so an edit survives only until
then and disagrees with the published archives in the meantime. Change the
`brews:` block in belay's `.goreleaser.yaml` instead.
